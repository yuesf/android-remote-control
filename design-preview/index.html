05

状态与文案

失败文案区分「码不存在」与「离线」；错误用页面内常驻条，不用 Toast；空态与锁屏黑屏为定稿字符串。

ERROR · 码不存在（常驻条，非 Toast）
配对码 K7M2 不存在，请向对方确认复制指引
ERROR · 设备离线（与上者不同）
设备 K7M2 当前离线，对方可能未开机或应用未运行复制指引
EMPTY · 无历史连接
还没有连接过设备。在上方输入对方的四位配对码开始。
EMPTY · 无在线设备
暂无在线设备
对方上线后会自动出现在这里
SESSION · 锁屏黑屏
对方屏幕已锁定，请让对方在本机解锁
控制端无法远程解锁，这是系统安全限制
NOTE · 被控常驻条
被控中·控制方：Pixel 8 Pro
三 tab 任意页、状态栏下 24dp 条，0↔24dp / 240ms 推开内容而非悬浮遮挡；不可关闭、不可滑动关闭、不随滚动。
浅底 #FBE3D5 / 字 #7A2305 / 点 #A8340C；深底 #3A1E12 / 字 #FFB287 / 点 #FF9159。右侧 16dp chevron_end + 12sp「被控详情」，48×48dp 命中 slab 且不遮挡首个可点元素。常驻条无呼吸。
SIGNAL DECK · 动效：连接状态切换 240ms · 被控角标 1600ms 仅 alpha 呼吸 · 按压 80ms · 进入会话 200ms scrim + 300ms 淡入 · 减少动态下全部静态化，图形与文字保留。
本页为设计提案预览，不改动 App 源码；Android 资源映射见 README.md 与 tokens/。
